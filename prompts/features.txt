Analyze the game mod title and description to extract:

1. **Mod Types** - Identify the type(s) of mod. Common types include but are not limited to:
   - overhaul (major gameplay/system changes)
   - patch (bug fixes, compatibility updates)
   - media (visual/audio content: textures, models, sounds, music)
   - QOL (quality of life improvements)
   - expansion (adds significant new content/areas)
   - utility (tools/helpers for players or modders)
   - cheat (gives player advantages)
   - translation (language localization)
   - library (software libraries, frameworks, dependencies)
   - ai generated (AI made some part of the mod: code, art, textures, voices,
     music, or text)

2. **Features** - Extract core features mentioned, but:
   - Remove all quantities, numbers, and measurements
   - Use plural form for countable items/concepts
   - Focus on the core concept/noun only
   - Consolidate similar terms into broad categories
   - Remove adjectives and descriptors unless they fundamentally change the concept
   - Group variants under the main category (e.g., "spacesuits" covers all types of spacesuits)
   - If three or more features are kinds of one broader thing, list only the broader thing
   - The most important features only, the ones a user would install this for
   - Never put a type name in the features array. "translation",
     "localization", "overhaul", "patch", "media", "QOL", "expansion",
     "utility", "cheat", "library" and "ai generated" are types only. A
     translation mod has the type "translation" and lists the content that it
     translates, or an empty features array

**Feature Consolidation Examples:**
- "dress spacesuit", "crew spacesuit", "spacesuit" → "spacesuits"
- "sealed protosuit", "protosuits" → "protosuits"
- "steel sword", "iron sword", "magic sword" → "swords"
- "leather armor", "plate armor", "armor" → "armor"
- "red cars", "blue cars", "vehicles" → "vehicles"
- "machine guns", "autocannons", "missile launchers", "laser cannons" → "weapons"
- "point-defense systems", "anti-aircraft systems", "shield generators" → "defenses"
- "wolves", "bears", "raptors" → "animals"

**Output Requirements:**
- Return valid JSON only
- Use this exact structure:
{
  "types": ["array", "of", "types"],
  "features": ["array", "of", "features"]
}

**Transformation Rules for Features:**
- "50 new weapons" → "weapons"
- "Improved graphics and 4K textures" → ["graphics", "textures"]
- "Adds 3 new characters and 15 quests" → ["characters", "quests"]
- "Fixes various bugs and crashes" → ["bug fixes", "crash fixes"]
- "Better UI with new inventory system" → ["UI", "inventory system"]
- "Adds a new weapon type" → "weapons"
- "Library for other modders" → ["library"] (in types)
- "German translation of the mod" → ["translation"] (in types, not in features)
- **For consolidation:** "Adds dress spacesuits, crew spacesuits, and sealed protosuits" → ["spacesuits", "protosuits"]
